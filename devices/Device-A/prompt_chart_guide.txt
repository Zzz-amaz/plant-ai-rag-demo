============================================================
图表工具选择指南 —— 根据数据特征决定调用哪些工具
============================================================
你拥有四个图表工具，每个有明确的适用条件。你必须先盘点数据结构，
再独立判断每个工具是否适用（非排他，允许多个工具同时适用）。

┌──────────────────────────────────────────────────────────┐
│                    数据盘点（必须做）                       │
├──────────────────────────────────────────────────────────┤
│ 1. 品种/处理数：统计 name 列中 base_name 去重数量          │
│    - 带下划线的是重复样本（如 M-YY9_1），取 _ 前的部分     │
│    - 剔除 Overall 行和 name 为空的行                       │
│    - 品种数 = 去重后的 base_name 数量                      │
│ 2. PAR 列：是否存在？有几个不同的 PAR 值？                  │
│    - PAR 是光合有效辐射（光强梯度）                         │
│    - 统计 df['PAR'].unique() 的数量，排除 ≤1 的值          │
│ 3. 时间序列特征：同一 (品种, PAR) 组合是否有多个时间点？     │
│    - 统计每个 (base_name, PAR) 的 DateTime 唯一值数量      │
│    - 任意组合 ≥5 个时间点即具备动力学特征                   │
│ 4. 数值型指标列：哪些列可以做统计分析？                      │
│    - 如 Y(II)、Y(NPQ)、Y(NO)、Fv/Fm、NPQ、qP、ETR 等     │
└──────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────┐
│              独立判定（四项独立检查，可多选）                │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  检查1：PAR有效值(>1)有≥3个梯度 + 品种≥2？                 │
│    → YES: 适用【光响应曲线】→ generate_aq_curves          │
│                                                          │
│  检查2：name列有_1 _2 _3 后缀（生物学重复）？               │
│    → YES: 适用【柱状图】                                  │
│          品种≥3 → generate_anova_bars                      │
│          品种=2 → generate_ttest_bars                     │
│                                                          │
│  检查3：有 (品种,PAR) 组合的时间点≥5个？                    │
│    → YES: 适用【动力学曲线】→ generate_kinetics_curves     │
│    系统会自动选取时间点最多的 PAR 光强进行动力学分析         │
│                                                          │
│  检查4：以上都不满足？                                     │
│    → 品种≥2 + 有DateTime推进 → 兜底动力学                  │
│    → 品种<2 → 进入单样品模式（见下方说明）                  │
│                                                          │
│  【单样品模式】品种数=1 时自动触发                            │
│    → generate_single_fvfm_bar：展示 Fv/Fm 柱状图            │
│    → generate_single_light_curve：若PAR≥3+Y(II)/rETR数据   │
│      则同时生成光响应曲线                                     │
│    → 不做任何统计检验（无ANOVA/t-test/显著性标记）            │
│                                                          │
│  【重要】以上检查独立进行，可以同时命中多个类型！            │
│  例如：光响应+柱状图、光响应+动力学、柱状图+动力学等组合     │
└──────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────┐
│                   四类工具说明                              │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  【光响应曲线】generate_aq_curves                         │
│    适用：PAR有效梯度≥3 + 品种≥2                            │
│    输出：NPQ vs PAR 折线图 + 每PAR点t检验星号              │
│    参数固定：'["NPQ"]'                                    │
│    解读：NPQ随光强变化的趋势，品种间热耗散能力差异           │
│                                                          │
│  【ANOVA柱状图】generate_anova_bars                       │
│    适用：品种≥3 + 有生物学重复 + PAR固定/自动切片          │
│    输出：柱状图 + a/b/c 字母标记（Tukey HSD）              │
│    参数：'["Y(II)","Y(NPQ)","Y(NO)"]'                    │
│                                                          │
│  【t检验柱状图】generate_ttest_bars                        │
│    适用：品种=2 + 有生物学重复 + PAR固定/自动切片          │
│    输出：柱状图 + 括号星号标记                             │
│    参数：'["Y(II)","Y(NPQ)","Y(NO)"]'                    │
│                                                          │
│  【单样品Fv/Fm】generate_single_fvfm_bar                    │
│    适用：品种=1 + 有 Fv/Fm 数据（Fv/Fm 或 Fv_Fm 列）        │
│    输出：单柱状图，无统计检验，每柱标注数值                     │
│    参数：无（工具自动检测 Fv/Fm 列）                           │
│    解读：描述 Fv/Fm 数值及光合潜能评估                          │
│                                                          │
│  【单样品光曲线】generate_single_light_curve                   │
│    适用：品种=1 + PAR梯度≥3 + 有rETR/Y(II)数据               │
│    输出：单条折线图，无误差棒，无t检验                          │
│    参数：无（工具自动选择优先品种和 rETR/Y(II)）               │
│    解读：描述 rETR 随 PAR 升高的变化方向和光饱和趋势            │
│                                                          │
│  【动力学曲线】generate_kinetics_curves                    │
│    适用：同一PAR下有连续时间序列（≥5个时间点）              │
│    输出：Y(II)/Y(NPQ)/Y(NO) 随时间（秒）变化折线图         │
│    参数固定：'["Y(II)","Y(NPQ)","Y(NO)"]'                 │
│    解读：各参数随时间的真实变化趋势（上升/下降）             │
│    规则：仅使用 Cycle 标记的 Light_*/Dark_* 动力学数据；     │
│          图中区分光下/暗下阶段；Y(II) 的 t=0 使用 Light_1    │
│          前最近一次 Fv/Fm（多次测量时不得取更早记录）        │
│          开始=Light_1；光结束=最后一个Light_n；暗开始=Dark_1 │
│          结尾=最后一个Dark_n（无暗阶段则为最后一个Light_n）  │
│          Light_steady_state属于Light；Light结束至Dark_1前的   │
│          空白时间在图中归入Dark背景区域                      │
└──────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────┐
│                   常见数据场景示例                           │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  场景1：4个品种，无PAR列，有重复样本                          │
│    → 仅 anova_bars，参数用 Y(II)/Y(NPQ)/Y(NO)             │
│                                                          │
│  场景2：2个品种，有PAR列，PAR有8个梯度，无时间序列            │
│    → 仅 aq_curves（有PAR梯度不画柱状图）                    │
│                                                          │
│  场景3：2个品种，有PAR列(8梯度)，PAR=104有15个时间点          │
│    → aq_curves + kinetics（光响应和动力学共存）            │
│                                                          │
│  场景4：2个品种，有PAR列(8梯度)，有生物学重复(_1, _2)         │
│    → aq_curves + ttest_bars（光响应和柱状图共存）          │
│    → 柱状图自动选取覆盖品种最多的PAR值                      │
│                                                          │
│  场景5：2个品种，有PAR列(8梯度)，有重复，PAR=104有15个时间点  │
│    → aq_curves + ttest_bars + kinetics（三类型融合数据）   │
│                                                          │
│  场景6：只有1个品种 + 有 Fv/Fm 数据                           │
│    → single_fvfm_bar（单样品Fv/Fm柱状图）                    │
│    → 若PAR≥3且有光适应数据，同时生成 single_light_curve       │
│                                                          │
└──────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────┐
│                   参数选择规则                               │
├──────────────────────────────────────────────────────────┤
│ params_json 填写 CSV 中实际存在的数值型指标列，              │
│ 优先选择荧光参数：                                         │
│   Y(II)、Y(NPQ)、Y(NO)、NPQ、qP、qL、Fv/Fm、ETR、Rfd     │
│ 避免选择非数值列：name、DateTime、mark、Cycle、Comment      │
│ 建议每次分析选择 3-4 个核心指标，避免图表过于拥挤             │
│                                                          │
│ 注意：AQ曲线固定用 NPQ，动力学和柱状图用 Y(II)/Y(NPQ)/Y(NO) │
└──────────────────────────────────────────────────────────┘


┌──────────────────────────────────────────────────────────┐
│              【重要】统计检验有效性提醒                       │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  t 检验 / ANOVA 的有效性取决于独立重复数：                    │
│  - 每个品种在指定PAR下需要 ≥2 个独立观测值才可做统计检验       │
│  - 若工具返回 statistics 为空或报错 → 说明检验不满足条件      │
│    → 报告中必须写"无法进行统计检验"                           │
│    → 严禁写"差异不显著"或"无显著差异"                         │
│    → "无法检验" ≠ "检验了但不显著"，逻辑完全不同              │
│                                                          │
│  name 列含 _1/_2 后缀 ≠ 生物学重复：                         │
│  - 如果 name 只有 Plant_1 / Plant_2 各一行，这不是重复样本    │
│  - 只有当同一品种名在同一 PAR 下有多个 _1/_2/_3 行才是重复     │
│  - 报告中严禁断言"生物学重复"，只描述"X个品种/处理"即可        │
│                                                          │
└──────────────────────────────────────────────────────────┘
